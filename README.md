# 投资模拟器

面向 iPad 浏览器的股票 / ETF / 基金模拟与策略回测应用。

## 当前功能
- 实时/近实时行情查询（Yahoo Finance Chart API）
- 日线历史数据下载
- 买入并持有、双均线、定期定额三种基础策略回测
- 虚拟账户、持仓、模拟买卖、交易记录
- localStorage 本地保存
- iPad / Safari / Chrome 响应式界面
- 数据层可通过 API 代理扩展，不把密钥放进前端

## 部署
直接开启 GitHub Pages 即可运行前端。若浏览器环境限制跨域，可在 Cloudflare Worker 等服务部署代理，并在“设置 → API 代理地址”填写 Worker 地址。

## 数据与风险
本项目用于软件开发、量化研究和教学模拟，不构成投资建议。第三方行情数据的授权、延迟、准确性和稳定性由对应服务商负责。
