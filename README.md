# 投资模拟器

面向 iPad 浏览器的股票、ETF、基金模拟与策略回测应用。

## 如何使用

### 1. 打开应用

在 iPad 的 Safari 或 Chrome 打开 GitHub Pages 页面。底部 6 个入口分别是：**首页、行情、回测、模拟、数据、设置**。核心功能不会因为 K 线、数据中心等辅助功能而挤到其他页面。

### 2. 查看真实行情与 K 线

进入“行情”，选择“自动识别 / 股票 / ETF / 基金”，输入代码后点“查询”。

- 美股：输入 `AAPL`、`MSFT`、`NVDA` 等。
- A 股：可输入 `600519`、`000001` 等六位代码，也可直接输入带交易所后缀的代码。
- ETF：输入 Yahoo Finance 可识别的 ETF 代码。
- 公募基金：**选择“基金”后输入六位基金代码**，例如 `000001`。基金页面使用历史单位净值，不把净值伪装成真实盘中 OHLC。
- 查询后会自动显示日 K；可切换 3 个月、1 年、5 年、最长约 40 年。实际能取得多少年由数据源和该标的上市/成立时间决定。

### 3. 做历史模拟投资

进入“模拟”，先选择标的、初始资金和历史区间，加载真实历史数据后从第一个交易日开始逐日推进。你可以上一交易日、下一交易日、跳 5/20 个交易日、播放，或者直接跳到某个已经加载的历史日期；只有当前模拟日期及之前的数据会出现在模拟 K 线和交易界面，不能在 2020 年的时点看到 2025 年的数据。

交易按当前历史时点执行并记录日期、价格、数量、费用和剩余现金。A 股继续执行最小交易单位与 T+1 规则。历史模拟和下面的“当前组合”是两个独立功能：前者用于重放历史决策，后者用于现在的多资产虚拟组合。

- 美股默认按 USD 行情、按“设置”中的 USD/CNY 汇率折算到账户总资产。
- A 股会按 100 股整数倍交易；科创板代码 `688xxx` 默认按 200 股整数倍。
- A 股卖出默认计入 0.05% 印花税，并限制当天买入当天卖出。
- ETF/股票按数量模拟；基金可以查看净值并进行虚拟交易，但目前不是券商真实委托模型。
- 顶部刷新按钮可重新获取持仓的最新价格。

### 4. 做当前组合

“模拟”页下方的“当前组合”是一个独立的多资产虚拟账户，可以同时持有股票、ETF、基金。它使用当前/手动成交价，不会改变历史回放的时间轴。

### 5. 做策略回测

进入“回测”，填写标的、资金、日期和策略后点“开始回测”。目前有：买入并持有、双均线 20/60、定期定额、RSI 30/70。

建议第一次使用直接保留默认参数，只修改标的和日期。回测会显示期末资产、累计/年化收益、最大回撤、Sharpe、Sortino、波动率、交易次数、费用、基准收益和相对基准，并绘制资金曲线与回撤曲线。

信号统一遵循“前一交易日数据产生信号 → 下一交易日开盘成交”，避免把未来数据带入当前交易决策。回测不是对未来收益的保证。

### 6. 导入自己的历史数据

进入“数据”，CSV 至少需要 `date,close`，推荐完整格式 `date,open,high,low,close,volume`。选择资产类型并选择文件后输入该数据对应的代码。导入后，本地数据会优先用于该标的历史查询/回测。

### 7. 备份与恢复

“数据”页可以导出账户 JSON，也可以导入以前的 JSON 备份。重置模拟账户会清空当前持仓和交易记录；如果需要保留记录，先导出备份。

### 8. 设置数据代理

如果浏览器直接访问第三方行情接口受跨域限制，在“设置”中填写已经部署好的 Cloudflare Worker 地址即可。留空时应用会尝试直接访问公开数据接口。

## 当前功能

- Yahoo Finance 行情与日线历史数据接口，可选 Cloudflare Worker 代理
- A 股六位代码自动转换为 Yahoo Finance 市场代码
- 虚拟账户、持仓、模拟买卖、手续费、美元兑人民币换算
- CSV 历史数据导入，可覆盖对应标的的回测数据源
- 买入并持有、双均线 20/60、定期定额、RSI 30/70
- 回测手续费、滑点、仓位比例、无风险利率
- 使用“前一交易日收盘产生信号 → 下一交易日开盘成交”，避免把当天收盘价同时当作信号和成交价
- 累计收益、年化收益、最大回撤、回撤持续时间、年化波动、Sharpe、基准收益、相对基准、交易次数
- 本地账户 JSON 备份与安全导入
- PWA 缓存静态资源，但不会缓存实时行情接口
- 日 K 图支持 OHLC 蜡烛、MA5 / MA20 / MA60，并针对缺失 OHLC 的数据自动使用收盘价回退，避免图表出现 NaN
- 历史模拟按交易日逐步推进，模拟 K 线严格裁剪到当前日期，交易函数拒绝未来日期成交
- 超过约 10 年的日线历史会自动拆分成多个时间段请求，合并去重后再交给回测/历史模拟
- GitHub Actions 自动进行 JavaScript 语法检查和回测单元测试
- iPad / Safari / Chrome 响应式界面

## 回测口径

回测引擎以日线 OHLC 数据为基础。策略信号默认只使用已经发生的数据：

- 买入并持有：区间开始后的第一个可执行交易日开盘建仓
- 双均线：使用前一日的 20 日与 60 日均线，在下一交易日开盘执行
- RSI：使用前一日 RSI，在下一交易日开盘执行
- 定期定额：按交易日周期投入虚拟资金
- 买入滑点向上、卖出滑点向下
- 手续费按成交金额计提
- 每日收盘进行持仓市值估算
- Sharpe 使用用户设置的年化无风险利率，并按 252 个交易日年化

目前仍未完整模拟 A 股涨跌停、停牌、成交量冲击、分红现金流和全部拆股/配股等公司行为；A 股最小交易单位、卖出印花税、手续费、滑点等基础参数已经进入回测引擎，但不同券商的实际费率仍可能不同，因此回测结果不能视为真实可成交结果。

## AI API：可选 ADHD 友好模式

Cloudflare Worker 新增独立的 `POST /api/chat`，通过 `adhdMode: true/false` 控制是否加载 `i-have-adhd` 仓库中的原始 `SKILL.md`。未传该字段时默认关闭。原有 `POST /api/assistant` 投资策略接口保持不变，避免破坏策略 JSON 输出。

部署和请求示例见 [ADHD_API.md](./ADHD_API.md)。通用聊天接口需要配置 `ADHD_CHAT_API_KEY` Secret；不要把该令牌放进 GitHub Pages 前端代码。

## 部署

直接开启 GitHub Pages 即可运行前端。若浏览器环境限制跨域，可部署 Cloudflare Worker 作为数据代理，并在“设置 → API 代理地址”填写 Worker 地址。

## 数据与风险

本项目用于软件开发、量化研究和教学模拟，不构成投资建议。第三方行情数据的授权、延迟、准确性和稳定性由对应服务商负责。


## 资产支持说明

- 美股股票：支持 AAPL、MSFT、NVDA 等 Yahoo Finance 可识别代码。
- A 股：六位代码可自动转换为交易所代码，也支持直接输入带后缀代码。
- ETF：支持 Yahoo Finance 可识别的 ETF。
- 中国公募基金：选择“基金”并输入六位基金代码，使用公开历史单位净值；基金净值不是盘中实时成交价。
- CSV：股票、ETF、基金均可导入自有历史数据，且本地数据优先用于回测。

基金回测目前按历史净值序列进行，不模拟具体基金的申购确认日、赎回到账日、申赎费率等产品级规则；这些参数应在后续按具体基金单独建模。
